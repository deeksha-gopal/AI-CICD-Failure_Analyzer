# Contributing

1. Create a feature branch.
2. Keep changes small and include unit tests for bug fixes.
3. Run `cd backend && python -m pytest -q`.
4. Run `cd frontend && npm ci && npm run build`.
5. Submit a pull request describing the behavior, testing, and relevant security/privacy considerations.

Never add genuine CI credentials, customer logs, or `.env` files to the repository. Sample logs must be synthetic.
